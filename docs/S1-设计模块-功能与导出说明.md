## 2. 三维场景设计页（Design.vue）功能

### 2.1 项目加载与渲染
- 进入页面弹出「选择加载项目」面板，加载后自动显示站点与管线。
- 支持站点→中心机房星型拓扑、直连/曼哈顿双路由渲染（数据驱动，与 QGIS 端一致）。
- 覆盖热力图：透明度 15%→45%、品红配色，前后端同步。

### 2.2 基站标签 / 机房标签（已拆分）
原「站点标签」单一开关拆分为两个**独立**复选框，互不干扰：
- **基站标签**：控制基站（站点）实体的名称/编号标注显隐。
- **机房标签**：仅控制中心机房（hub / machine room）实体的标注显隐。

> 实现：`useSiteManager.js` 中机房标注独立为 `machine_room_label_*` 实体，`showMachineRoomLabels` + `toggleMachineRoomLabels()` 单独控制；基站标注沿用原 `showLabels` / `toggleLayer('label', …)` 链路。

### 2.3 FTTH 叠加与信息查看（已人话化）
右上角「FTTH 叠加」勾选后，在三维地球上叠加 FTTH 全要素（站点 / 光交箱 / 楼栋 / 光缆）。**点击任意要素弹出信息框（原生 infoBox）**，字段已做中文转译：

| 要素 | 中文标签 | 关键字段 |
|---|---|---|
| 入户光节点 | PBO 入户光节点 | 容量（芯光纤）、归属汇聚点、经纬度 |
| 分支箱 | BPE 楼栋/路边分光箱 | 容量（芯光纤）、覆盖户数、工程类型、经纬度 |
| 小区汇聚点 | PM 小区光汇聚点 | 容量、归属、经纬度 |
| 楼栋 | IMB 楼栋 | 覆盖状态、归属机房 |
| 光缆 | 干线 TRANSPORT / 配线 DISTRIBUTION / 入户 DROP | 起讫、芯数、长度 |

> 实现：`Design.vue` 的 `toggleFtthOverlay` 为每个实体补 `description`（中文说明），并保留 `infoBox: true` 以启用原生点击弹窗。早期版本因未绑定 `description` / 点击回调，导致「勾选后点不开信息」——本次已修复。

### 2.4 模型入口（已移除）
顶部工具栏原「模型」入口按钮（跳转 `/models`）已删除，仅保留「区域」「FTTH」入口，避免与 S1 设计主流程无关的干扰入口。

### 2.5 数据导出
- 支持将当前三维场景（含高德底图）导出截图（`toDataURL`，已修复蓝底问题）。
- 矢量成果走 QGIS 端导出（见第 3 节），导入 CAD 后仍为可编辑矢量。

## 3. QGIS 插件 · CAD 矢量导出

### 3.1 矢量 DXF 导出
- 导出为**矢量 DXF**（非栅格化），导入 CAD 后为可编辑图层，含图框/比例尺/指北针/图签/要素编号等装饰层。
- 装饰层以模型坐标绘制，映射到 `FRAME / SCALE / NORTH / TITLE / LABEL` 五个 CAD 图层。
- 兼容多 QGIS 版本 DXF 接口（`setLayers` / `addLayers` / `writeToFile` 三种签名交叉尝试，优先 QIODevice 写出）。

### 3.2 导出后闪退修复
- **克隆层零副作用导出**：导出前克隆图层，源图层与工程不被触碰。
- **临时层模块级保活**：克隆层 / 装饰内存层放入模块级 `_GLOBAL_KEEPALIVE`，存活至 `QgsDxfExport` 析构之后，规避悬空指针导致的 QGIS 原生崩溃（闪退）。
- 装饰文字层由 `ezdxf` 后处理写入，关闭原生标注导出以规避崩溃。

### 3.3 覆盖盲区修复
- 覆盖热力图由分类渲染改为**分级范围渲染**（`QgsGraduatedSymbolRenderer` + HexArgb 保透明），解决连续 RSRP 无法精确匹配的问题。
- 布局导出补 `setCrs(4326)` + 白底 + 可见图层过滤 + `refresh`，修复导出 PDF 灰底。
