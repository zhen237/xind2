## 二、比赛要求

### 2.1 核心攻关内容

参赛团队可围绕以下方向自主选择切入点：

| 子赛题 | 说明 | 我们的选择 |
|--------|------|------------|
| 子赛题1 | 面向专业GIS平台的通信工程智能辅助设计 | ✅ 选择 |
| 子赛题2 | 多源异构工程数据融合 | ❌ 跳过 |
| 子赛题3 | 基于行业标准的设计智能审查 | ✅ 选择 |
| 子赛题4 | 设计成果向施工指令的自动转化 | ✅ 选择 |
| 子赛题5 | 施工过程智能监管 | ✅ 选择 |

### 2.2 成果形式

1. **可运行成果** - 可运行系统原型、软件插件、算法程序
2. **技术方案文档** - 研究背景、技术路线、功能设计
3. **验证报告** - 测试环境、测试方法、结果分析
4. **对比实验数据** - 原始数据、实验结果
5. **演示材料** - 演示视频、操作说明

### 2.3 具体指标要求

| 子赛题 | 指标要求 |
|--------|----------|
| 子赛题1 | 效率提升≥30%，或减少50%以上手动绘图操作 |
| 子赛题3 | 审查覆盖率≥80%，关键风险识别准确率≥95% |
| 子赛题4 | 施工准备资料编制时间缩短50%以上 |
| 子赛题5 | 违章行为识别准确率≥85%，隐蔽工程验真准确率≥90% |

## 三、评分标准

### 3.1 创新性（30分）

- **创新水平（15分）** - 技术创新程度、问题分析准确性
- **创新成效（15分）** - 应用结合程度、示范价值

### 3.2 产业应用价值（30分）

- **问题解决实效（15分）** - 关键指标达成情况
- **推广价值（15分）** - 场景适配性、可复制性

### 3.3 系统性（40分）

- **方案完整性（20分）** - 材料完整性、逻辑严密性
- **系统成熟度（20分）** - 可运行系统、验证充分性
