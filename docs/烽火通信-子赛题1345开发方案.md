## 3. 子赛题1：QGIS 基站智能辅助设计

### 3.1 核心目标（P0，必做）

#### 3.1.1 参数化设计面板

**功能**: 在 QGIS 中打开一个 Dock Widget，用户输入设计参数，一键生成基站布局方案。

**输入参数**:
- 设计区域：在地图上框选矩形或多边形
- 频段：700MHz / 2.6GHz / 3.5GHz / 4.9GHz
- 覆盖半径要求：500m / 1000m / 2000m
- 天线类型：全向 / 定向（可选扇区数 3/6）
- 天线挂高范围：25m-50m
- 已有站点约束：加载已有基站图层，避开重叠覆盖

**自动生成内容**:
- 蜂窝拓扑站址布局（六边形网格，考虑地形修正）
- 每站点：经纬度、塔高建议、天线方位角、下倾角
- 覆盖半径可视化（同心圆缓冲区）
- 站址自动避让：建筑物、水域、生态保护区（基于 OSM 数据）

**QGIS 实现**:

#### 3.1.2 覆盖可视化

**功能**: 基于选定传播模型，渲染覆盖热力图。

- 实现 Okumura-Hata 传播模型（支持 700M/2.6G/3.5G 频段）
- 生成 RSRP 覆盖热力图（栅格图层），分级着色
- 覆盖盲区自动标识（低于阈值的区域高亮）
- 支持 DEM 高程修正

#### 3.1.3 标准图纸自动生成

**功能**: 利用 QGIS Layout Manager 自动生成标准设计图纸。

- 图纸模板：A3/A4，包含图框、图例、指北针、比例尺
- 自动输出：站址分布总图、单站详图、覆盖分析图
- 导出格式：PDF / PNG / SVG

### 3.2 扩展方向（P1，加分项）

#### 3.2.1 AI 选址推荐引擎

**功能**: 基于历史优质站址数据训练 ML 模型，对多个候选方案打分排序。

- 训练特征：地形坡度、人口密度（OSM/公开数据）、距离道路距离、已有站点距离
- 模型：XGBoost 回归（评分预测），部署为本地 pkl 文件
- 输出：候选站址列表 + 综合评分 + 各维度得分
- 云端 fallback：调用 Claude API 做方案评审（"Given these 5 candidate sites, rank them by feasibility..."）

#### 3.2.2 管线路径设计

**功能**: 在基站设计的基础上，扩展通信管线的自动路径规划。

- 基于 OSM 道路网络的最短路径路由
- 电力线交越检测
- 管线长度自动统计

#### 3.2.3 机房设备布局

**功能**: 机房内机柜/电源/空调自动排布。

- 基于约束的二维布局算法
- 冷热通道计算
- 生成机房平面图 + BOM

## 4. 子赛题3：基于行业标准的设计智能审查

### 4.1 核心目标（P0，必做）

#### 4.1.1 多维度安全审查引擎

**审查维度**:

**① 电力线交越安全审查**
- 输入：基站选址方案 + 电力线路图层
- 规则：基站塔体与高压电力线水平距离 ≥ 1.5倍塔高（依据 DL/T 741）
- 规则：垂直交叉时，最小垂直距离 ≥ 4m（10kV）/ ≥ 6m（35kV）
- 输出：交越点位置、距离、合规判定

**② 电磁辐射合规审查**
- 输入：基站发射功率、天线增益、下倾角
- 规则：公众暴露限值（依据 GB 8702 / ICNIRP），计算安全距离
- 输出：辐射安全边界范围、敏感区域（学校/医院）距离检查

**③ 与已有设施的空间冲突检测**
- 输入：新增站点 + 已有站点/建筑物图层
- 规则：同运营商站点间距 ≥ 200m（同频段）/ ≥ 100m（异频段）
- 规则：站点与其他建筑最小安全距离
- 输出：冲突点列表、冲突类型

**④ 地形安全审查**
- 输入：DEM 高程数据 + 站点位置
- 规则：坡度 > 30° 为不良站址，需标记
- 规则：位于洪水风险区（根据 DEM 汇流分析）需标记
- 输出：风险站点列表

## 5. 子赛题4：设计成果向施工指令自动转化

### 5.1 核心目标（P0，必做）

#### 5.1.1 BOM 自动生成引擎（QGIS 插件端）

**功能**: 从基站设计方案图层中自动提取物料清单。

**提取逻辑**:
- **塔桅系统**: 从塔高/塔型参数 → 塔段数量、连接件、螺栓规格数量
- **天馈系统**: 天线型号 × 数量 → 天线 + 馈线长度（基于站高+水平距离） + 馈线接头 × 2/根
- **电源系统**: 设备总功率 → 电源模块型号 × 数量 + 备用电池容量
- **机房/机柜**: 设备列表 → 机柜规格 × 数量 + 走线架长度
- **接地系统**: 塔高/FM → 接地体数量 + 接地线长度
- **辅材**: 按比例自动计算（扎带、胶泥、防水胶带等）

## 8. 数据获取方案

由于没有组委会提供的正式数据，我们需要自行获取公开数据 + 构造合成数据。

### 8.1 公开数据源

| 数据 | 来源 | 获取方式 |

| 电力线路 | OSM power=line | 从 OSM 提取 |
| 行政区划 | 天地图 / OSM | [DataV.GeoAtlas](http://datav.aliyun.com/portal/school/atlas/area_selector) |

### 8.2 合成数据生成

对于无法获取的数据，用脚本生成合理样例：

- **8 个虚拟基站设计样例**（覆盖：城市密集区/产业园区/城乡结合部）
- **历史 CAD 图纸样例**（用于演示数据融合能力，可自行绘制）
- **施工现场照片**（网络搜集典型施工场景，标注违规/合规标签）
- **30 个基站样例数据**（真实坐标，基于 OSM 和 DEM 计算合理参数）

### 8.3 验证区域：武汉洪山区/光谷（15km×15km）

**选定区域**: 武汉市洪山区光谷广场周边，以光谷广场为中心 7.5km 半径范围，总面积约 180km²。

**区域优势**:
- 真实地形数据丰富（DEM 30m 精度可用）

- 包含多种典型场景：城市密集区（光谷核心）、产业园区、城市边缘（城乡结合部）、小型山体（喻家山/马鞍山）

- 光纤通信需求集中，管线场景可扩展

## 11. 风险与注意事项

### 11.1 技术风险

| 风险 | 等级 | 对策 |
|------|------|------|
| QGIS 插件调试困难，PyQGIS 文档不完善 | 高 | 先用 QGIS Python Console 交互式验证每个模块，再封装为插件 |
