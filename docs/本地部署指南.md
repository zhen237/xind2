## 一、环境要求

> **详细版本说明**: 请参考 [环境依赖版本.md](环境依赖版本.md) 获取各组件的最低版本、推荐版本和版本兼容性说明。

### 1.1 必须安装的软件

| 软件 | 版本要求 | 用途 |
|------|----------|------|
| JDK | 17 | 运行Spring Boot后端（项目固定版本）|
| Maven | 3.9+ | 构建后端项目 |
| MySQL | 8.0+ | 数据库服务 |
| Node.js | 18+ | 运行前端项目 |
| QGIS | 3.34+ | QGIS插件开发 |

### 1.2 环境变量配置

```bash
# Windows
set JAVA_HOME=C:\Program Files\Java\jdk-21
set MAVEN_HOME=C:\Program Files\Apache\maven-3.9
set PATH=%JAVA_HOME%\bin;%MAVEN_HOME%\bin;%PATH%
```

## 二、启动步骤

### 2.1 启动M01认证服务

```bash
cd packages/m01-auth/backend
mvn spring-boot:run
```

**端口**: 8080

### 2.2 启动M03后端

```bash
cd packages/m03-bim-gis/backend
mvn spring-boot:run
```

**端口**: 8083

### 2.3 启动M04后端

```bash
cd packages/m04-delivery/backend
mvn spring-boot:run
```

**端口**: 8084

### 2.4 启动M03前端

```bash
cd packages/m03-bim-gis/frontend
npm install
npm run dev
```

**端口**: 5174

### 2.5 启动M04前端

```bash
cd packages/m04-delivery/frontend
npm install
npm run dev
```

**端口**: 5175

### 2.6 启动M06门户

```bash
cd packages/m06-portal
npm install
npm run dev
```

**端口**: 5173

## 四、QGIS插件安装

### 4.1 安装步骤

1. 打开QGIS Desktop
2. 菜单 → 插件 → 管理和安装插件
3. 点击"已安装"选项卡
4. 找到"Base Station Design"
5. 勾选启用

### 4.2 插件位置

```
C:\Users\{用户名}\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\qgis-plugin-complete\
```

## 五、常见问题

### 5.1 MySQL连接失败

**问题**: M04后端启动失败，提示MySQL连接错误

**解决**: 检查MySQL密码配置，修改 `application.yml` 中的密码

### 5.2 QGIS插件不显示

**问题**: QGIS中看不到插件

**解决**:
1. 检查 `__init__.py` 文件是否存在
2. 清除QGIS缓存
3. 重启QGIS

### 5.3 前端启动失败

**问题**: npm run dev 失败

**解决**:
1. 删除 `node_modules` 文件夹
2. 重新运行 `npm install`
3. 再运行 `npm run dev`
