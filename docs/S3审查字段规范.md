# S3 智能审查 · QGIS 插件导出字段规范

> 适用对象：S1 QGIS 插件（`BaseStationDesignPlugin` / `qgis-plugin` 仓库）开发者
> 目标：让插件导出的 GeoJSON 能被 S3 规则引擎**真实比对**（产出「合规 / 违规」），而非全部落入「待核查(pending)」。
> 关联模块：M03 设计前端 `useDesignState.submitToS3Review` → M03 后端 `submitToS3` → S3 Java `/s1/receive` → S3 Python 引擎 `/check`
> 实测基准：2026-08-29 全链路验证（任务 27）——24 条规则中 21 条已可真实比对，4 条因本规范未覆盖字段而 pending（见文末）。

---

## 1. 数据放置位置约定

S3 引擎读取数据有三个来源，插件必须按位置导出：

| 数据源 | 在 GeoJSON 中的位置 | 引擎读取方式 | 适用规则 |
|--------|---------------------|--------------|----------|
| **站点 / 设备** | `features[].properties`（Point 要素） | `devices[]`，字段提升到**设备顶层** | EL-001/002/003、FT-001、全部 B-5 规则 |
| **机房** | 根级 `properties.machine_rooms[]` | 作为独立 `device` 推送 | FT-001（容量）、EL-003（接地，若声明） |
| **馈线电缆** | 根级 `properties.cables[]` | 作为 `deviceType=communication_cable/power_cable` 推送 | EL-001、EL-002 |
| **管线埋深** | 根级 `properties.pipeline[]` | `design_data.pipeline` | GD-001 |
| **接地网** | 根级 `properties.groundGrid` | `design_data.extraData.groundGrid` | LP-004 |

> 说明：M03 前端在推送时会把站点 `properties` 中下列**设备级字段提升到设备顶层**（供 EL-001/002/003/FT-001 直读），同时保留 `params` 给 B-5 规则读取：
> `material, burialDepth, groundingResistance, cableDiameter, bendingRadius, crossSection, actualCurrent, capacity, fibreUsed`。
> 因此插件只要把这些字段写在要素的 `properties` 里即可，无需自己区分顶层/params。

---

## 2. 设备类型（deviceType）映射

引擎按 `deviceType` 决定该设备适用哪些规则。插件务必在站点/电缆/机房要素中声明规范 `deviceType`：

| 要素类别 | 推荐 deviceType | 触发的真实校验 |
|----------|-----------------|----------------|
| 基站铁塔 / 杆塔 | `tower` | EL-003 接地电阻、及全部以 `params` 读取的 B-5 规则 |
| 通信机房 | `communication_room`（或 `room`） | FT-001 容量（需 capacity+fibreUsed）、EL-003（仅 `communication_room` 计入接地） |
| 馈线 / 通信电缆 | `communication_cable` | EL-001 弯曲半径、EL-002 载流量 |
| 电力电缆 | `power_cable` | EL-001、EL-002 |
| 未声明（回退 `site`） | 仅能推送，EL-003 **不计入**（不在接地类型表中） | —— |

> ⚠️ 站点**不要**用裸 `site`：虽可推送，但 `site` 不在 `GROUNDING_TYPE_MAP` 中，EL-003 会判为「待核查」。导出铁塔请统一用 `tower`。

## 3. 字段映射表（规则 → 所需 properties 字段）

### 3.1 设备顶层字段（EL-001 / EL-002 / EL-003 / FT-001）

| 规则 | 名称 | 字段名（properties 内） | 类型/单位 | 国标依据 | 判定逻辑 | 示例值 |
|------|------|--------------------------|-----------|----------|----------|--------|
| EL-001 | 电缆弯曲半径 | `cableDiameter` | number, mm | GB 50217 | 弯曲半径 ≥ 缆径×(15~20) | `15` |
| EL-001 | 电缆弯曲半径 | `bendingRadius` | number, mm | GB 50217 | 同上 | 合格 `300` / 违规 `120` |
| EL-002 | 电缆截面选型(载流量) | `crossSection` | number, mm² | GB 50217 | 载流量按截面×材质查表，留 1.25 倍裕度 | `25` |
| EL-002 | 电缆截面选型(载流量) | `actualCurrent` | number, A | GB 50217 | 实际电流 ≤ 额定载流量 | `130` |
| EL-002 | 电缆截面选型(载流量) | `material` | enum | GB 50217 | `copper`/`aluminum`（铜/铝） | `copper` |
| EL-003 | 接地电阻 | `groundingResistance` | number, Ω | GB 50169 / DL/T 621 | 杆塔/机房接地电阻 ≤ 4~10Ω | 合格 `3.5` / 违规 `6.5` |
| FT-001 | 光缆/分纤箱容量 | `capacity` | number, 芯/端口 | GB 51158 | 已用 ≤ 额定容量 | `10` |
| FT-001 | 光缆/分纤箱容量 | `fibreUsed` | number, 芯/端口 | GB 51158 | 同上 | 合格 `6` / 违规 `13` |

> EL-001/EL-002 仅对 `deviceType ∈ {communication_cable, power_cable, cable, copper_cable, comm_cable, optical}` 的设备校验；
> EL-003 仅对 `deviceType ∈ {tower, lightning_rod, transformer, substation, power_substation, distribution_room, communication_room, computer_room, equipment}` 校验；
> FT-001 对任意携带 `capacity`+`fibreUsed` 的设备校验（机房最典型）。

### 3.2 管线埋深（GD-001，根级 `properties.pipeline[]`）

| 字段 | 类型/单位 | 说明 | 示例 |
|------|-----------|------|------|
| `layingType` | enum | `direct`(直埋) / `pipe`(管道) | `direct` |
| `scenario` | enum | `urban`(城区) / `suburb`(郊外) | `urban` |
| `burialDepth` | number, m | 实测埋深 | 合格 `0.9` / 违规 `0.5` |

依据 GB 51158（直埋）/ GB 50373（管道）差异化最小埋深阈值。

### 3.3 接地网（LP-004，根级 `properties.groundGrid`）

| 字段 | 类型/单位 | 说明 | 示例 |
|------|-----------|------|------|
| `gridX` | number, m | 接地网网格 X 向边长 | `7`（违规，应 ≤5） |
| `gridY` | number, m | 接地网网格 Y 向边长 | `7` |

依据 GB 50057-2010：接地网网格尺寸应 ≤ 5m×5m。

### 3.4 B-5 规则库（设备 `params` 读取，写在要素 properties 即可）

以下字段写在要素 `properties` 中，引擎从 `device.params` 读取；缺失则判「待核查」。

| 规则 | 名称 | 字段 | 单位 | 国标 | 合规方向 |
|------|------|------|------|------|----------|
| EL-004 | 绝缘子污秽等级 | `insulatorLevel`, `requiredPollutionLevel` | 级 | GB/T 26218.1 | `insulatorLevel ≥ requiredPollutionLevel` |
| EL-005 | 开关耐压试验 | `withstandVoltage`, `ratedVoltage` | kV | GB 50150 | `withstandVoltage ≥ 1.5×ratedVoltage` |
| EL-006 | 变压器油位 | `oilLevelPercent` | % | GB/T 6451 | `≥ 20` |
| EL-007 | 保护定值 | `protectionSettingActual`, `protectionSettingComputed` | — | DL/T 587 | 偏差 ≤ 5% |
| EL-008 | 母线搭接面 | `contactResistance` | μΩ | GB 50149 | `≤ 200` |
| LP-001 | 避雷针高度 | `rodHeight`, `requiredRodHeight` | m | GB 50057 | `rodHeight ≥ requiredRodHeight` |
| LP-002 | 引下线连续性 | `downConductorResistance` | Ω | GB 50057 | `≤ 0.2` |
| LP-003 | SPD 选型 | `spdUc`, `systemVoltage`, `spdIn` | V / V / kA | GB 50057 | `Uc ≥ 1.15×Uac` 且 `In ≥ 5kA` |
| LP-005 | 等电位联结 | `equipotentialResistance` | Ω | GB 50057 | `≤ 0.1` |
| ST-001 | 基础承载力 | `bearingCapacity`, `designLoad` | kPa | GB 50007 | `≥ 1.2×designLoad` |
| ST-002 | 焊缝探伤 | `weldPassRate` | % | GB 50205 | `≥ 98` |
| ST-003 | 混凝土强度 | `concreteStrengthActual`, `concreteStrengthDesign` | MPa | GB 50204 | `≥ 设计等级` |
| ST-004 | 构件变形 | `deformationActual`, `deformationLimit` | mm | GB 50205 | `≤ 允许值` |
| EM-001 | 电磁辐射 | `emRadiation`, `emLimit` | — | GB 8702 | `≤ 国标限值` |
| EM-002 | 无线电干扰 | `radioInterference`, `radioLimit` | dBμV/m | GB 7349 | `≤ 允许限值` |
| EM-003 | 静电防护 | `staticPotential` | V | GB 50054 | `≤ 1000` |
| CM-001 | 消防设施 | `fireFacilityStatus` | enum | GB 50016 | `正常/完好/有效` |
| CM-002 | 通风系统 | `ventilationRateActual`, `ventilationRateRequired` | — | GB 50019 | `≥ 设计要求` |
| CM-003 | 照明照度 | `illuminanceActual`, `illuminanceStandard` | lx | GB 50034 | `≥ 国标` |

## 4. 最小可用导出模板（示例 GeoJSON 片段）

```jsonc
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": { "type": "Point", "coordinates": [111.0, 35.0] },
      "properties": {
        "site_id": "BTS-001", "name": "基站001",
        "deviceType": "tower",                 // 铁塔 → 触发 EL-003
        "groundingResistance": 3.5,            // EL-003
        "insulatorLevel": 3, "requiredPollutionLevel": 3,   // EL-004
        "withstandVoltage": 30, "ratedVoltage": 20,        // EL-005
        "oilLevelPercent": 45,                          // EL-006
        "protectionSettingActual": 100, "protectionSettingComputed": 100, // EL-007
        "contactResistance": 150,                      // EL-008
        "rodHeight": 35, "requiredRodHeight": 30,      // LP-001
        "downConductorResistance": 0.1,                // LP-002
        "spdUc": 300, "systemVoltage": 220, "spdIn": 10, // LP-003
        "equipotentialResistance": 0.05,               // LP-005
        "weldPassRate": 99,                            // ST-002
        "emRadiation": 8, "emLimit": 10,               // EM-001
        "staticPotential": 600,                        // EM-003
        "fireFacilityStatus": "正常",                   // CM-001
        "ventilationRateActual": 120, "ventilationRateRequired": 100, // CM-002
        "illuminanceActual": 300, "illuminanceStandard": 200          // CM-003
      }
    }
  ],
  "properties": {
    "cables": [
      {
        "cableId": "CAB-1", "deviceType": "communication_cable",
        "cableDiameter": 15, "bendingRadius": 300,   // EL-001
        "crossSection": 25, "actualCurrent": 80, "material": "copper"  // EL-002
      }
    ],
    "pipeline": [
      { "pipeId": "PIPE-1", "layingType": "direct", "scenario": "urban", "burialDepth": 0.9 }  // GD-001
    ],
    "groundGrid": { "gridX": 5, "gridY": 5 }   // LP-004（≤5 合格）
  }
}
```

## 5. 当前覆盖率与待补字段（2026-08-29 实测）

全链路推送同一份 enriched 数据后，24 条规则中：

- ✅ **可真实比对（21 条）**：EL-001/002/003、FT-001、GD-001、LP-001/002/003/004/005、EL-004/005/006/007/008、ST-002、EM-001/003、CM-001/002/003。
- ⏳ **仍待核查（4 条，因插件未导出这些字段）**：
  - `EM-002` 无线电干扰 → 需导出 `radioInterference`, `radioLimit`
  - `ST-001` 基础承载力 → 需导出 `bearingCapacity`, `designLoad`
  - `ST-003` 混凝土强度 → 需导出 `concreteStrengthActual`, `concreteStrengthDesign`
  - `ST-004` 构件变形 → 需导出 `deformationActual`, `deformationLimit`

> 这 4 条即为「数据完整度预检面板」应提示补全的字段。补全后覆盖率可达 100%。

## 6. 送审流程回顾（端到端）

1. QGIS 插件导出上述 GeoJSON（含 `properties` 设备字段 + 根级 `cables`/`pipeline`/`groundGrid`）。
2. M03 设计前端「加载本地文件」→「送审 S3 审查」按钮。
3. `submitToS3Review` 组装 `devices`（站点/机房/电缆，设备级字段提升到顶层）+ `pipeline` + `extraData.groundGrid`，POST M03 后端 `submitToS3`。
4. M03 后端 `S3ReviewClient` 转发至 S3 `/api/v1/s3/review/s1/receive`（白名单免 token）。
5. S3 Java 缓存 `design_data` → 异步调用 Python 引擎 `/check` → 结果落库。
6. Portal「S1→S3 看板」读取任务结果，展示**覆盖率 / 违规分级 / 待核查清单**。
