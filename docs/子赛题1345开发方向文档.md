```
┌─────────────────────────────────────────────────────────────────────┐
│                    M06 统一前端门户 (Vue 3)                           │
│                    登录 → 动态菜单 → iframe 加载子应用                 │
└──────┬──────────────┬──────────────┬──────────────┬─────────────────┘
       │              │              │              │
       ▼              ▼              ▼              ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│  M03 前端    │ │  M04 前端    │ │  M05 前端    │ │  大屏中心     │
│  Vue+Cesium  │ │  Vue+Element │ │  Vue+ECharts │ │  Vue+ECharts │
│  3D可视化    │ │  审查/监管UI │ │  运维监控    │ │  数据大屏    │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

### 1.2 技术栈

| 层面 | 技术 | 用途 |
|------|------|------|
| QGIS插件 | Python 3.9+ / PyQGIS / PyQt5 | 桌面GIS智能设计 |
| 空间分析 | QGIS Processing / GDAL / Shapely | 覆盖计算、拓扑分析 |
| ML选址 | scikit-learn / XGBoost | 站址推荐评分 |
| CV识别 | YOLOv8 / Claude Vision API | 安全违章识别 |
| 后端 | Spring Boot 3.1.10 + MyBatis-Plus | M03/M04 REST API |
| 前端 | Vue 3 + Vite + Element Plus + CesiumJS | 可视化 |
| QGIS数据存储 | PostgreSQL + PostGIS | QGIS空间数据 |
| Web数据库 | MySQL 8.0 | 业务数据 |
| 文件存储 | MinIO | 照片/视频/图纸 |
| CV微服务 | FastAPI + YOLOv8 | 独立CV检测服务 |

## 二、子赛题1：智能辅助设计

### 2.1 技术方案

**目标**: 基于QGIS平台的通信工程智能辅助设计

**核心功能**:
1. 参数化设计面板 - 用户输入参数，一键生成基站布局
2. 蜂窝拓扑生成 - 六边形网格，考虑地形修正
3. 覆盖可视化 - Okumura-Hata传播模型，RSRP热力图
4. 标准图纸生成 - QGIS Layout Manager

**技术实现**:
- QGIS Desktop Plugin (Python)
- PyQt5 UI设计
- PyQGIS API调用
- 覆盖计算算法

**指标要求**:
- 效率提升≥30%
- 减少50%以上手动绘图操作

### 2.2 负责人

- **人A**: QGIS插件开发
- **人E**: M03前端3D可视化

## 三、子赛题3：智能审查

### 3.1 技术方案

**目标**: 基于行业标准的设计智能审查

**核心功能**:
1. 电力线交越安全审查 - DL/T 741标准
2. 电磁辐射合规审查 - GB 8702标准
3. 空间冲突检测 - 站点间距、覆盖重叠
4. 地形安全审查 - 坡度、洪水风险

**技术实现**:
- M04后端审查引擎
- 规则引擎 + Spring IoC
- JTS空间计算
- 审查报告生成

**指标要求**:
- 审查覆盖率≥80%
- 关键风险识别准确率≥95%

### 3.2 负责人

- **人C**: M04后端审查引擎

## 五、子赛题5：施工过程监管

### 5.1 技术方案

**目标**: 施工过程智能监管

**核心功能**:
1. CV安全违章识别 - 安全帽、围挡、违章行为
2. 施工进度跟踪 - 实时进度、偏差检测
3. 隐蔽工程验真 - 影像结构化分析

**技术实现**:

- M04后端监管模块
- MinIO文件存储
- 违规记录管理

**指标要求**:
- 违章行为识别准确率≥85%
- 隐蔽工程验真准确率≥90%

### 5.2 负责人

- **人D**: CV视觉检测微服务
