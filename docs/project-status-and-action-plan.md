## 八、关键注意事项

### 8.1 代码规范

- 遵循ES6+语法规范
- Python代码遵循PEP 8
- Java代码遵循阿里巴巴Java开发手册
- 所有代码必须添加中文注释

### 8.2 命名规范

- 变量: camelCase (前端) / snake_case (Python)
- 类名: PascalCase
- 文件名: kebab-case
- 数据库表名: snake_case

### 8.3 错误处理

- 所有API调用必须包含try-catch
- 用户操作必须有反馈提示
- 日志记录必须包含时间戳和上下文

### 8.4 性能要求

- 首屏加载时间 < 3秒
- API响应时间 < 500ms
- 内存占用 < 100MB
- 帧率 > 30fps

## 九、开发流程

### 9.1 分支管理

```
main          # 主分支 (生产环境)
├── develop   # 开发分支
│   ├── feature/m03-xxx    # 功能分支
│   ├── bugfix/xxx         # 修复分支
│   └── hotfix/xxx         # 紧急修复
```

### 9.2 提交规范

```
<type>(<scope>): <subject>

类型:
- feat: 新功能
- fix: 修复Bug
- docs: 文档更新
- style: 代码格式
- refactor: 重构
- test: 测试
- chore: 构建/工具

示例:
feat(m03): 添加参数化设计功能
fix(qgis): 修复站点删除同步问题
```

### 9.3 代码审查

- 所有PR必须经过至少1人审查
- 测试通过率必须100%
- 代码覆盖率 > 80%

## 十四、快速启动指南

### 14.1 启动后端

```bash
cd packages/m03-bim-gis/backend
mvnw spring-boot:run
```

### 14.2 启动前端

```bash
cd packages/m03-bim-gis/frontend
npm install
npm run dev
```

### 14.3 启动Python服务

```bash
cd packages/m03-topology-engine
pip install -r requirements.txt
python main.py
```

### 14.4 启动QGIS插件

## 十五、常见问题

### Q1: 数据库连接失败

```
检查application.yml中的数据库配置
确认MySQL服务正在运行
检查防火墙设置
```

### Q2: 前端依赖安装失败

```bash
npm cache clean --force
rm -rf node_modules
npm install
```

### Q3: Python服务启动失败

```bash
pip install --upgrade pip
pip install -r requirements.txt
```
