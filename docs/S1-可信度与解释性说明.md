> 版本: v1.0.0（2026-07-20）

---

## 1. 为什么需要可信度

S1 的覆盖分析存在**两类数据来源**，其可信程度天然不同：

| 来源 | 字段 `rsrpSource` | 含义 | 可信度 |
|------|------------------|------|--------|
| 模型仿真 | `simulated` | 由 Okumura-Hata 路径损耗模型估算（站点无实测值时、或 500m 代表值） | 中（受地形 / 建筑遮挡建模简化影响） |
| 实测 / 现场勘测 | `measured` | 由现场勘测或导入的 RSRP 真值（见契约 A 的 `/sites/measured`、`/sites/import`） | 高 |

仅给出"平均 RSRP -85 dBm"不足以让评审 / 下游判断**这个设计有多可信**。"可信度与解释性"补丁解决两件事：
1. **解释性**：明确说明设计依据的是仿真还是实测（数据基底），不把估算当真值。
2. **量化可信度**：每站给出 0–100 的可信度，整体聚合为单一分数 + 等级，边缘站（RSRP 接近覆盖门限）明确标为低可信。

## 2. 可信度模型

### 2.1 单站可信度

```
margin   = RSRP − RSRP_COVERAGE_THRESHOLD        // 距覆盖边缘的余量(dB)
conf_raw = clamp(50 + margin × 2.2, 5, 99)       // 门限处=50%，每超出1dB +2.2
conf     = round(conf_raw × sourceFactor)
sourceFactor = measured ? 1.0 : 0.85            // 仿真打折，体现模型不确定性
```

- `RSRP_COVERAGE_THRESHOLD = -100 dBm`（与盲区判定 `-100 dBm` 一致，口径统一）。
- 裕量为正且越大 → 越可信；裕量接近 0（边缘站）→ 约 50%，明确"不确定"；裕量为负（低于门限）→ < 50%，提示可能盲区。
- 仿真来源统一 ×0.85，直观反映"估算不如实测可靠"。

### 2.2 整体可信度

```
overall = mean(各站 confidence)
level   = overall ≥ 80 ? '高' : overall ≥ 60 ? '中' : '低'
```

### 2.3 数据基底（设计依据）

| 条件 | `basis` |
|------|---------|
| 全部仿真 | 模型仿真（Okumura-Hata 路径损耗） |
| 全部实测 | 实测 / 现场勘测主导 |
| 混合 | 混合（仿真 + 实测） |

报告内同时展示 `measuredCount` / `simulatedCount`，让评审一眼看清"这份设计有多少是靠实测撑起来的"。

## 3. 前端呈现

- `useCoverageAnalysis` 新增 `coverageConfidence` 计算属性，随站点数据自动重算。
- 覆盖报告弹窗（也是 Word 导出内容）新增 **「四、设计依据与可信度」** 章节：
  - 数据基底徽章（仿真=灰 / 实测=青 / 混合=紫）+ 实测 / 仿真计数；
  - 自然语言解释（整体分数 + 等级 + 依据 + 实测占比 + 仿真局限提示）；
  - 可信度口径脚注（门限、公式、来源系数）。
- 当无 RSRP 数据时，章节显示"未获得 RSRP 数据，无法计算可信度"，不报错。

## 4. 验证（sample run）

输入 4 站（A 仿真 -82、B 仿真 -98、C 实测 -75、D 仿真 -105）：

| 站 | RSRP | margin | source | confidence |
|----|------|--------|--------|-----------|
| A | -82 | 18 | simulated | 76 |
| B | -98 | 2 | simulated | 46（边缘，低） |
| C | -75 | 25 | measured | 99（封顶） |
| D | -105 | -5 | simulated | 33（低于门限） |

→ `overall=64%（中）`，`basis=混合（仿真 + 实测）`，`实测 1 站 / 仿真 3 站`。逻辑符合预期。

---

## 5. 已知局限与后续

- 仿真可信度 ×0.85 为经验折扣，非统计置信区间；若需严格不确定性量化，可引入蒙特卡洛（对路径损耗参数抽样）生成置信带。
- 当前可信度仅基于 RSRP 裕量，未纳入**站址避让合规率**、**管线可达性**等维度；后续可扩展为多因子加权。
- `rsrpSource` 的 `measured` 标注依赖上传侧契约（见契约 A 的 `/sites/measured`、`/sites/import`），务必由上游正确传入，否则可信度会整体偏低估。
