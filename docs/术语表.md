## 一、FTTH 法语业务术语（摩洛哥 JAD-MARJANE 竣工数据集）

本项目 S1 实际交付路线采用主办方提供的**摩洛哥 FTTH 光纤到户竣工数据**，大量字段与实体为法语缩写。

| 术语 | 法语全称 | 中文含义 | 备注 |
|------|----------|----------|------|
| **FTTH** | Fiber To The Home | 光纤到户 | 本路线业务域 |
| **IMB** | Immeuble | 楼宇 / 用户需求点 | 51 个需求点，含户数 |
| **NRO** | Nœud de Raccordement Optique | 光分配节点（局端） | 网络顶层节点 |
| **ZNRO** | Zone NRO | NRO 服务区 | 区域划分 |
| **PM** | Point de Mutualisation | 共享点 / 光交汇聚点 | 缆路由根节点之一 |
| **ZPM** | Zone PM | PM 服务区 | |
| **BOITE** | Boîte | 光交箱（统称） | 分两类 ↓ |
| **BPE** | Boîte de Péripherie Extérieure | 外围分歧箱 | `fonction=Fenetrage`，字段 `CAPACITE FO` |
| **PBO** | Point de Branchement Optique | 用户光分支点 | `Extremite` / `NB_LOGEMEN prises` |
| **SRO** | Sous-Répartiteur Optique | 光分路器 | |
| **CABLE** | Câble | 光缆 | 含 `ORIGINE`→`EXTREMITE` 端点坐标，按类型分色 |
| **PTECH** | Point Technique | 技术点 | |
| **INFRASTRUCTURE** | — | 基础设施 | 管道/杆路等 |
| **Tiroir** | Tiroir | 熔接盘 | 纤芯级占位项，待外部数据 |
| **Fenêtrage** | — | 跳接/成端 | BPE 功能字段值 |

## 二、技术术语

| 术语 | 含义 | 项目中的角色 |
|------|------|--------------|
| **BIM** | 建筑信息模型 | 三维设计载体 |
| **GIS** | 地理信息系统 | 空间数据底座（Cesium/OpenLayers 渲染） |
| **RSRP** | 参考信号接收功率 | 基站覆盖分析指标 |
| **BOM** | Bill of Materials，物料清单 | S4 由设计成果自动转化的施工物料清单 |
| **CAD 融合** | DWG/DXF 与 GIS 数据统一 | S2 核心：解析→坐标系转换→融合 |
| **数字孪生** | Digital Twin | S5 m05-twin-ops 大屏实时映射 |
| **拓扑引擎** | Topology Engine | S1 蜂窝/光缆拓扑生成（Python） |
| **EMQX** | MQTT 消息服务器 | S5 设备物联网实时数据 |
| **YOLOv8** | 目标检测模型 | S5 隐蔽工程影像检测 |
| **SAM** | Segment Anything Model | 图像语义分割，S5 管线轮廓提取 |
| **Flyway** | 数据库版本迁移工具 | 各模块独立迁移表（`flyway_schema_history_sN`） |
| **Cesium** | 三维地球 JS 库 | S1 三维可视化（GitHub Pages 已适配） |
| **DWG / DXF** | AutoCAD 图纸格式 | S2 解析输入 |
| **GeoJSON** | 地理要素 JSON 格式 | S2 解析统一输出 |
| **CGCS2000** | 中国大地坐标系（EPSG:4490） | S2 坐标系转换源之一 |
| **WGS84** | 世界大地坐标系（EPSG:4326） | 统一归一到此 |
