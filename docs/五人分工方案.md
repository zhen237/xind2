## 二、模块分工

### 2.1 人A：M03 + QGIS插件

**负责模块**:
- M03后端（设计数据API）
- M03前端（3D可视化）
- QGIS插件（基站智能设计）

**主要工作**:
1. QGIS插件开发
   - 蜂窝拓扑生成
   - 覆盖计算（Okumura-Hata模型）
   - 标准图纸导出
   - 避让检测
   - 数据同步到M03后端

2. M03后端开发
   - 设计数据API
   - 站点数据API
   - GeoJSON导出API

3. M03前端开发
   - 3D可视化（CesiumJS）
   - 站点显示
   - 覆盖热力图

**技术栈**:
- Python 3.9+ / PyQGIS / PyQt5
- Spring Boot 3.1.10 + MyBatis-Plus
- Vue 3 + CesiumJS

**代码位置**:
- QGIS插件: `qgis-plugin/`
- M03后端: `packages/m03-bim-gis/backend/`
- M03前端: `packages/m03-bim-gis/frontend/`

---

### 2.2 人B：QGIS插件·BOM

**负责模块**:
- QGIS插件BOM生成器

**主要工作**:
1. BOM自动生成
   - 物料清单提取
   - 分类统计
   - 价格估算

2. BOM导出
   - Excel导出
   - PDF导出
   - JSON导出

3. BOM同步
   - 同步到M04后端
   - 数据格式转换

**技术栈**:
- Python 3.9+
- openpyxl (Excel导出)
- requests (API调用)

**代码位置**:
- QGIS插件BOM: `qgis-plugin/bom_generator/`

**负责模块**:
- M04后端（审查引擎、BOM管理、监管模块）

**主要工作**:

   - 空间冲突检测
   - 地形安全审查

2. BOM管理

3. 监管模块

**技术栈**:

**代码位置**:
