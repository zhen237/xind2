## 二、⚠️ 启动铁律（必看）
**端口 3455 被 WorkBuddy 自身占用**（`WorkBuddy.exe --port 3455`，是 agent 子进程，**不是业务服务**）。
Bash 启动 shell 可能继承到 `SERVER_PORT=3455` 环境变量，导致 Spring 的 `server.port: ${SERVER_PORT:8083}` 解析成 3455 而启动失败。

✅ 正确启动方式（CLI 参数优先级最高，覆盖环境变量）：
```bash
cd packages/m03-bim-gis/backend
SERVER_PORT= "C:/Program Files/Eclipse Adoptium/jdk-21.0.11.10-hotspot/bin/java.exe" \
  -jar target/m03-bim-gis-1.0.0.jar --server.port=8083
```
❌ **绝对不要 kill 3455 端口的进程**（那是 agent 自己，杀了对话会断）。

## 四、接口路径清单（易踩坑）
- 列表接口：`/api/m03/project`、`/region`、`/model`、`/device`（**不要**写 `/xxx/list`，会匹配 `/{id}` 报 `NumberFormatException`）
- DesignController 在包 `com.comm.m03.design.controller`（不在 `com.comm.m03.controller`）
- 设计相关：`POST /api/m03/design`(上传)、`POST /api/m03/design/generate`、`GET /api/m03/design/templates`、`GET /api/m03/design/tasks`(**复数**)、`GET /api/m03/design/{projectId}`、`GET /api/m03/design/{projectId}/geojson`
- 放行规则：共享模块默认放行 `/api/m03/**`；无需 JWT 即可调用（内网联调用）

## 五、QGIS↔前端联调架构
```
QGIS 插件(PyQGIS)  ──HTTP POST──▶  M03 后端 :8083  ──▶  MySQL(comm_platform)
                                      ▲   │
前端 M03(Vue+Cesium :9000) ──读──┘   └─(generate/execute 调拓扑引擎 :9001)
   ↑ 经 M06 Portal(:5173) iframe 嵌入
```
- QGIS 插件把设计数据 POST 到 `http://localhost:8083/api/m03/design`（或 `/design/generate`）
- 前端从同一 `:8083` API 读取并渲染到 Cesium 地球
- 注意：`/design/generate`、`/design/tasks/{id}/generate` 会调用拓扑规划引擎(`TOPOLOGY_ENGINE_URL`，默认 `:9001`)，该引擎未启动时这类计算接口会失败，但 upload/templates/tasks 不受影响
