How to Run

三步启动

需要环境：JDK 17+ / Maven / Node 18+ / MySQL 8 / MinIO

1

初始化数据库

执行建表 SQL，创建 MySQL 用户并授予权限；启动本地 MinIO 服务。

mysql -uroot -p < m03_init.sql
2

启动后端

修改 application.yml 中的数据库与 MinIO 连接信息后启动。

cd backend && mvn spring-boot:run
3

启动前端

安装依赖并启动 Vite 开发服务器，浏览器访问 5174 端口。

cd frontend && npm i && npm run dev
