M02 录制操作指南

共 4 段视频，每段对应一个导航页签，按顺序录制即可

视频1 · 开场白（约40s）

  1. 停留在「CAD文件管理」页，从上到下移动鼠标扫过文件列表
  2. 口述：模块名称、技术栈（Spring Boot + proj4j + DXF解析）、负责功能
  3. 点击「东湖基站设计图.dxf」行的「解析」→ 自动进入「DXF解析」页，结束录制

视频2 · DXF解析与实体提取（约60s）

  1. 进入「DXF解析」页，点击「开始解析」按钮
  2. 展示进度条推进 + 左侧CAD线框图逐实体绘制
  3. 解析完成 → 展示右侧实体列表（类型/图层/坐标）+ 图层分类徽标
  4. 点击不同图层，左侧高亮对应实体
  5. 点击「下一步：坐标转换」进入下一页

视频3 · 坐标系转换（约50s）

  1. 进入「坐标转换」页，展示源坐标系 EPSG:4549（CGCS2000 3度带）→ 目标 EPSG:4326（WGS84）
  2. 点击「执行转换」→ 展示坐标表逐行转换动画（投影米 → 经纬度）
  3. 展示下方迷你地图：红点（源投影位置）→ 蓝点（转换后经纬度）位置变化
  4. 说明转换精度优于0.1米，点击「下一步：融合输出」

视频4 · CAD→GIS融合与输出（约80s）

  1. 进入「融合结果」页，点击「执行融合」按钮
  2. 展示进度条 + 2D地图逐要素渲染（建筑物/道路/管线/铁塔按图层着色）
  3. 仿真完成 → 展示统计卡片（要素总数/类型分布）+ 右下角图例
  4. 点击「导出 GeoJSON」→ 真实下载 .geojson 文件
  5. 点击「导出 CSV」→ 真实下载要素明细，结束录制
