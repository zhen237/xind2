## 1. 模块拆分粒度原则

每个「子赛题」再细分为三层：
- **B** = 后端 Spring Boot (Java)
- **E** = Python 算法引擎 (FastAPI 3.10)
- **F** = 前端 Vue 3 + Element Plus + Cesium

每个 B/E/F 再按"功能切片"继续拆分为 1~N 个可独立交付的「小模块」，每个小模块 = 一个 PR + 一个验收用例 (AC)。

```
  → S*-F-* (各前端 4-5 页)        → COMMON-01 (联调契约)

  → I1 S2→S1 → I2 S1→S3 → I3 S1/S3→S4 → I4 S4→S5 → I5 S5→S3
```

## 5. 单模块交付模板（每个小模块都要走这个流程）

每个「小模块」都会按以下顺序产出：
1. **设计**: 数据模型 / API 契约 / 类图（如需）
2. **代码**: 完整可运行的源码 + 配置
3. **测试**: 单元测试 + 至少一个 AC 用例
4. **文档**: README + 如何本地启动
5. **可演示**: 一条命令能跑起来的最小验证
