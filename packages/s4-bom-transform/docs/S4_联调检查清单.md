## 一、数据源切换配置（3 个服务各管各的）

### 1. Python 引擎（8100）
`engine/.env` 或环境变量：

```
S4_DATA_SOURCE=real
S4_S1_BASE_URL=http://<S1服务地址>:<端口>
```

切换后引擎的 `GET {S1_BASE_URL}/api/s1/design/tasks/{designTaskId}` 拉取真实设计清单。

### 2. dev-proxy（8090）
启动前设置环境变量：

```
S4_DATA_SOURCE=real
S1_REAL_URL=http://<S1服务地址>:<端口>
```

S1 详情、S3 审查结果自动转发真实接口；请求失败会**降级 mock + 打印 WARN**，保证联调期页面可用。

### 3. Java 后端（8090，当前未运行）
`application.yml`：

```yaml
s4:
  integration:
    data-source: real
    s1-url: http://<S1服务地址>:<端口>
    s3-url: http://<S3服务地址>:<端口>
    s5-url: http://<S5服务地址>:<端口>
    auth-token: "<m01-auth JWT>"
```

### 造价口径对齐 QGIS 原版（2026-09-27 第三轮，本地提交未推送）

按交接说明 §3.1「造价估算是真实实算」+ §5.1「取其口径」深挖，发现 S4 造价算法与 QGIS `calculate_pipeline_cost`（design_engine/pipeline.py:634）存在**结构性口径偏差**并完成对齐（cost_configs.json v1.1）：

| 维度 | 对齐前（v1.0） | 对齐后（v1.1，= QGIS 原版） |
|------|------|------|
| 施工费 | 每米综合价（直埋45/管道80/架空35） | **按敷设方式分项实算**：直埋=土方(宽=管径/1000+0.6，深=埋深+0.1)×50+回填×30；管道=土方(宽0.6，深=埋深+0.2)×60+回填×40+人孔；架空=无土方 |
| 附属物 | 接头盒 500m 间距 + 人孔 300m 间距（不分类型） | 直埋：标石(100m)+接头盒(2000m)；管道：人孔(**100m**)+接头盒(2000m)；架空：电杆(50m杆距)+拉线(每公里0.3条)+接头盒(2000m) |
| 费率 | 管理费5%/利润7%/税金9%（级联基数） | **管理费15%/利润5%/税金9%，均以直接费(材料+施工)为基数**（QGIS calculate_pipeline_cost 尾段口径） |
| 材料桶 | 仅光缆 | 光缆+管道+标石+接头盒+电杆+拉线（QGIS material_cost 全量） |

实现细节：

- `cost_configs.json` 新增 `type_cost_configs` 区块（QGIS `models/pipeline.py:236-262` 数值逐项照录：标石80/100m、人孔3000/100m、电杆1500/50m、拉线500×0.3条/km、接头盒2000m 等）。
