## 技术架构

### 数据模型
```
Site（站点）
├── site_id: 站点编号
├── name: 站点名称
├── longitude/latitude: 坐标
├── site_type: 类型（MACRO/SMALL/INDOOR）
├── tower_height: 塔高
└── connected_to: 连接的机房ID

Pipeline（管线）
├── pipeline_id: 管线编号
├── start_site_id: 起始站点
├── end_site_id: 终止站点
├── pipeline_type: 类型（直埋/管道/架空）
├── length: 长度（米）
├── depth: 埋深（米）
└── coordinates: 路由坐标列表

MachineRoom（机房）
├── room_id: 机房编号
├── name: 机房名称
├── longitude/latitude: 坐标
├── room_type: 类型（汇聚/接入）
├── capacity: 容量（可接入基站数）
└── connected_sites: 连接的基站列表
```
