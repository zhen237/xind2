# QGIS 通信基站智能设计插件 - 使用指南

## 概述

本插件为通信基建工程提供基站智能辅助设计能力，支持从基站选址、覆盖分析到管线路由规划的全流程设计。插件集成了 Okumura-Hata 传播模型、蜂窝拓扑生成、管线共享路由算法等核心算法。

**版本**: v0.2.1  
**支持 QGIS 版本**: 3.34 LTR（推荐）/ 3.28+  
**核心功能**: 蜂窝拓扑生成、覆盖分析、管线设计、工程量报表导出、方案同步

## 1. 安装与启动

### 1.1 安装方式

#### 方式一：直接复制（推荐）
1. 将 `qgis-plugin/` 文件夹复制到 QGIS 插件目录
2. 插件目录路径：
   - Windows: `C:\Users\<用户名>\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\`
   - Linux: `~/.local/share/QGIS/QGIS3/profiles/default/python/plugins/`
   - macOS: `~/Library/Application Support/QGIS/QGIS3/profiles/default/python/plugins/`

#### 方式二：ZIP 安装
1. 将 `qgis-plugin/` 打包为 `qgis-plugin.zip`（不含外层目录）
2. 在 QGIS 中：插件 → 管理并安装插件 → 从 ZIP 安装

### 1.2 启动插件

1. 打开 QGIS
2. 点击菜单栏：插件 → 基站智能设计
3. 或点击工具栏图标（基站图标）
4. 插件面板将显示在地图右侧

## 2. 快速上手流程

插件采用六步向导式设计，按顺序完成即可生成完整设计方案：

```
第一步：加载底图 → 第二步：选择区域 → 第三步：设置参数
    ↓
第六步：分析与导出 ← 第五步：管线设计 ← 第四步：生成基站
```

**典型工作流示例（5分钟完成）**:
1. 点击"高德卫星图"加载底图
2. 缩放地图到目标区域，点击"使用当前可视范围"
3. 设置频段为 3.5GHz，塔高 45 米，宏站，城市场景
4. 点击"一键生成蜂窝拓扑"，等待生成站点
5. 点击"在地图上点击添加机房"，在地图上点击放置机房
6. 设置管线类型为"直埋光缆"，点击"生成管线"
7. 点击"生成覆盖热力图"查看覆盖效果
8. 点击"导出工程量报表 (CSV)"导出报表

## 3. 各步骤详细说明

### 第一步：加载底图

| 按钮 | 功能 |
|------|------|
| 高德卫星图 | 加载高德卫星影像底图（推荐） |
| OSM地图 | 加载 OpenStreetMap 矢量地图 |

**提示**: 建议使用高德卫星图，可清晰看到地形和建筑物分布。

### 第二步：选择设计区域

| 按钮 | 功能 |
|------|------|
| 使用当前可视范围 | 将当前地图窗口范围设为设计区域 |
| 清除 | 清除已选择的区域 |

**注意事项**:
- 选区面积建议 < 10 km²，最大不超过 50 km²
- 选区太小可能无法生成有效站点（至少需要一个站间距的面积）
- 选区太大可能导致生成时间过长

### 第三步：设置基站参数

| 参数 | 说明 | 默认值 | 可选值 |
|------|------|--------|--------|
| 频段 | 通信频段，影响站间距和覆盖范围 | 3.5GHz | 700MHz / 2.6GHz / 3.5GHz / 4.9GHz |
| 站间距 | 根据频段自动计算的理想站间距（只读） | 随频段变化 | - |
| 塔高 | 基站铁塔高度 | 45 米 | 20-60 米 |
| 基站类型 | 站点类型，影响覆盖特性 | 宏站 | 宏站 / 微站 / 室内站 |
| 扇区数 | 天线扇区配置 | 3（三扇区） | 0-6 |
| 场景 | 环境类型，影响传播模型 | 城市 | 城市 / 郊区 / 农村 |

**频段配置参考**:

| 频段 | 频率 | 理想站间距 | 覆盖半径 | 适用场景 |
|------|------|-----------|----------|----------|
| 700MHz | 700MHz | 2.5km | 3-4km | 广覆盖、农村 |
| 2.6GHz | 2600MHz | 1.2km | 1.5-2km | 城区覆盖 |
| 3.5GHz | 3500MHz | 0.8km | 1-1.5km | 高密度城区 |
| 4.9GHz | 4900MHz | 0.5km | 0.5-1km | 热点区域 |

### 第四步：生成基站布局

| 按钮 | 功能 |
|------|------|
| 一键生成蜂窝拓扑 | 自动生成六边形蜂窝站点布局 |
| 手动添加基站 | 在地图上点击添加单个基站 |
| 清除所有站点 | 删除所有已生成的站点 |
| 加载避让数据 | 加载 GeoJSON 格式的避让区域（如湖泊、文物保护区） |
| 清除避让 | 清除已加载的避让数据 |

**站点表格字段说明**:

| 字段 | 说明 |
|------|------|
| 站点ID | 自动生成的唯一标识 |
| 名称 | 站点名称 |
| 站型 | MACRO/SMALL/INDOOR |
| 场景 | URBAN/SUBURBAN/RURAL |
| 塔高(m) | 安装高度 |
| 频段 | 当前频段 |
| 频率(MHz) | 载波频率 |
| 功率(W) | 发射功率 |
| 方位角 | 天线方向 |
| 覆盖半径(km) | 计算的覆盖半径 |
| 站间距(km) | 到相邻站点的距离 |
| 坐标 | 经纬度坐标 |

**操作按钮**:
- 定位到选中站点：地图缩放至选中站点位置
- 删除选中站点：删除表格中选中的站点
- 频段对比：生成不同频段的覆盖对比图

### 第五步：管线设计

| 功能区域 | 说明 |
|----------|------|
| 机房位置 | 设置汇聚机房位置（地图点击或手动输入坐标） |
| 管线参数 | 选择管线类型、路由类型、是否启用共享路由 |
| 生成管线 | 根据基站和机房位置生成管线路由 |
| 清除管线 | 删除所有管线 |

**管线类型**:

| 类型 | 价格(元/米) | 适用场景 |
|------|------------|----------|
| 直埋光缆 | 15 | 郊区、农田、空地 |
| 通信管道 | 45 | 城市道路、已有管道 |
| 架空光缆 | 18 | 道路两旁、有杆路资源 |

**路由类型**:
- 直线路径：基站到机房的最短直线距离
- 曼哈顿路径：先水平后垂直，适合城市道路网格

**共享路由**:
- 启用后，多基站到同一机房的管线会共享重叠路段
- 可显著减少总工程量（通常节省 20-40%）

### 第六步：分析与导出

| 按钮 | 功能 |
|------|------|
| 生成覆盖热力图 | 基于 Okumura-Hata 模型计算并渲染覆盖范围 |
| 导出工程量报表 (TXT) | 导出文本格式的工程量和成本报表 |
| 导出工程量报表 (CSV) | 导出 CSV 格式报表（含明细表、工程量表、成本表、汇总表） |
| 导出当前视图 | 导出 PDF 格式的设计图纸 |
| 保存方案 | 保存当前设计方案到本地文件 |
| 加载方案 | 加载已保存的设计方案 |
| 同步到 M03 后端 | 将设计方案同步到 Web 平台后端 |

## 4. 功能详解

### 4.1 蜂窝拓扑生成

采用六边形网格算法，根据指定站间距在选区内生成均匀分布的站点。

**算法流程**:
1. 根据选区边界生成六边形网格中心点
2. 过滤超出边界的点
3. 如果加载了避让数据，过滤位于避让区域内的点
4. 根据频段配置计算每个站点的覆盖参数
5. 在地图上渲染站点标记

### 4.2 覆盖分析

基于经典的 **Okumura-Hata 传播模型** 计算覆盖范围：

**模型公式**:
```
L = 69.55 + 26.16 × log10(f) - 13.82 × log10(ht)
    + (44.9 - 6.55 × log10(ht)) × log10(d) - a(hr)
```

其中：
- f: 频率 (MHz)
- ht: 发射天线高度 (m)
- d: 距离 (km)
- a(hr): 接收天线高度修正因子

**RSRP 计算**:
```
RSRP = 发射功率(dBm) + 天线增益(dBi) - 路径损耗(dB) - 阴影衰落(dB)
```

**热力图颜色映射**:
- 红色（-110dBm以下）：覆盖盲区
- 黄色（-110~-80dBm）：弱覆盖
- 绿色（-80~-50dBm）：良好覆盖

### 4.3 管线设计

**管线工程量计算**:

| 管线类型 | 计算项 |
|----------|--------|
| 直埋光缆 | 土方量 = 长度 × 沟宽 × 埋深 |
| 通信管道 | 土方量 + 人孔数量 |
| 架空光缆 | 电杆数量 + 拉线数量 |

**成本估算**:
- 材料费：光缆、管道、电杆等
- 施工费：开挖、回填、架设等
- 管理费：施工管理费
- 利润：按比例计算
- 税金：按比例计算

**共享路由算法**:
1. 生成所有基站到机房的管线
2. 识别共享路段（多条管线经过的相同路段）
3. 共享路段只计算一次工程量
4. 输出节省比例

### 4.4 避让功能

支持加载 GeoJSON 格式的避让区域数据，自动过滤站点和管线：

**支持的避让类型**:
- Polygon（多边形）：如湖泊、河流、文物保护区、军事禁区
- Point（点）：如已有基站、障碍物

**使用方法**:
1. 准备 GeoJSON 文件（WGS84 坐标）
2. 在第四步点击"加载避让数据"
3. 选择 GeoJSON 文件
4. 生成站点时会自动避开避让区域

## 6. 常见问题

### Q1: 提示"选区面积太小"怎么办？

**原因**: 选区面积小于一个站间距的面积，无法生成有效站点。

**解决**: 缩小地图视图，扩大可视范围后重新选择。

### Q2: 覆盖热力图生成失败？

**可能原因**:
- 基站功率太低
- 覆盖半径太小（高频段衰减快）
- 频率太高导致衰减过快

**解决**: 尝试降低频率（如从 4.9GHz 改为 3.5GHz）或增大塔高。

### Q3: 管线生成失败？

**可能原因**:
- 未生成基站
- 未设置机房位置

**解决**: 先完成第四步生成基站，再在第五步设置机房位置。

### Q4: 插件加载失败？

**可能原因**:
- QGIS 版本低于 3.28
- Python 依赖缺失（如 shapely）

**解决**:
- 升级 QGIS 到 3.28+
- 在 QGIS Python 控制台运行：
  ```python
  import sys
  sys.path.append(r'path\to\qgis-plugin')
  from design_engine.coverage import okumura_hata_path_loss
  ```

### Q5: 如何导入演示数据？

插件自带测试数据可通过以下方式导入：
1. 使用 `scripts/init-mysql.sql` 创建数据库表和测试数据
2. 在第六步点击"同步到 M03 后端"，将本地设计同步到平台
