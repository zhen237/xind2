# QGIS 插件操作流程（S1 智能辅助设计）

> 面向比赛演示与团队对齐的**实际操作手册**。每一步对应插件面板（`ui/design_dock.py`）上的一个按钮/工具。
> FTTH 真实数据已**织入主流程**（不再只是旁路按钮），设计建立在真实现网之上。

## 面板长什么样

插件面板已**严格按这 9 步从上到下排列**：左侧是 9 个步骤按钮（带进度条 + 运行日志），
右侧是对应步骤的操作区，每页底部有「← 上一步 / 下一步 →」，照着点就能走完全流程。

## 前置：起环境

| 服务 | 端口 | 作用 | 启动方式 |
|------|------|------|----------|
| M03 后端 | 8083 | 设计生成 / 真实数据查询 | `packages/m03-bim-gis/backend` → `mvn spring-boot:run --server.port=8083` |

| QGIS | — | 插件运行平台 | 打开 QGIS 3.44 → 插件管理器重载 `qgis-plugin-complete` |

> 真实数据（FTTH）可选但**强烈建议**：让设计跑在真实网络而非空白画布上，演示加分。

## 主流程（9 步，FTTH 已集成）

```
① 起环境 ──────────── 后端8083 + 拓扑引擎9001 (+ LLM 9002)
② 加载真实 FTTH 现网 ─ 【加载并符号化 FTTH 图层】→ 8 层进画布当底图
③ 覆盖缺口识别 ────── 【覆盖缺口识别 · 智能建议站点】→ 红点=盲区楼栋，绿点=建议补站
④ 框选设计区域 ────── 【在地图上框选区域】工具 → 圈定设计范围（替代 CAD 手绘边界）
⑤ 填参数 ─────────── 基站密度/间距 · 管线类型(直埋/管道/架空) · 机房容量
⑥ 一键生成 ───────── 【由拓扑引擎生成】→ 拓扑引擎算站点+管线+机房并落库
⑦ 场景构建 ───────── 覆盖热力图 + 管线 + 基站 + FTTH 真实层 四层叠加
⑧ 自检 & 联动 ─────── 【高亮自检异常要素】(38/45条规则红框) + 【联动查询】点选看附近要素
⑨ 标准出图 ───────── 【导出 FTTH 标准 PDF】→ 含图例/比例尺/指北针（含设计层与真实层）
```

### 逐步说明

**② 加载真实 FTTH 现网**
- 点【加载并符号化 FTTH 图层】→ 选 `docs/真实数据/Plan_de_récolement/Shape/` 目录（含 8 个 .shp）
- 系统按法语 FTTH 标准（`ftth/field_map.py`）分类着色：IMB 楼栋 / SITE 站点 / BOITE 光箱 / CABLE 光缆 / PTECH 杆井 / INFRASTRUCTURE 管道 / ZNRO·ZPM 覆盖区
- 画布自动飞到数据范围

**③ 覆盖缺口识别（S1 增强核心）**
- 点【覆盖缺口识别 · 智能建议站点】
- 算法（`ftth/coverage_gap.py`）：合并 ZNRO+ZPM 覆盖区面 → 逐 IMB 楼栋 `contains` 判断 → 区外楼栋=缺口（红圈）
- 对缺口楼栋按 400m 网格聚类 → 每簇一个**建议新增 NRO 候选站点**（绿点，字段含覆盖楼栋数/住户容量）
- 日志输出：`楼栋 N | 已覆盖 X | 缺口 Y → 建议 Z 处补站`

**④ 框选设计区域**
- 用框选工具在地图圈一块地（可以框在缺口附近，让新设计补盲区）

**⑤ 填参数**
- 在面板填：基站模板(宏站/微站/室分)、间距/密度、管线类型、机房容量
- 可选：用 LLM 服务把自然语言需求（"在缺口A建宏站覆盖500户"）转成参数

**⑥ 一键生成**
- 点【由拓扑引擎生成】→ `POST /api/m03/design/generate`
- 拓扑引擎（:9001）返回 sites + devices(铁塔/天线/RRU/BBU/电源/传输) + coverage_polygons
- 后端双路径：引擎通→用引擎结果；引擎挂→本地回退（只产 sites），幂等防重复

**⑦ 场景构建**
- 覆盖热力图（Okumura-Hata 算的覆盖多边形）+ 管线 + 基站 + FTTH 真实层 叠加成一张完整设计场景

**⑧ 自检 & 联动**
- 【高亮自检异常要素】：跑 38/45 条行业标准规则，异常要素红框高亮（已修 QGIS 3.44 多部件几何坑）
- 【联动查询：开】+ 半径(m)：在地图点一下，自动高亮附近 FTTH(红)/基站·管线·机房(蓝)——验证设计是否与现网冲突

**⑨ 标准出图**
- 【导出 FTTH 标准 PDF】：输出含图例/比例尺/指北针的标准设计图（设计层 + 真实层同图）

## 效率对照（比赛硬指标：效率≥30% / 减手动≥50%）

| 环节 | 传统 CAD 手绘 | 本插件 |
|------|--------------|--------|
| 画 10 基站+连线 | ~2 小时 | 框选+填参 ~3 分钟 |
| 覆盖缺口判断 | 人工目测（易漏） | 一键识别 ~2 秒 |
| 出标准图 | 手动排版 ~30 分 | 一键 PDF ~10 秒 |
| **总计** | **~2.5 小时** | **~5 分钟** |

效率提升 ≈ **96%**，远超门槛。
