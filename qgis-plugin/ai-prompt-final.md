# 背景

我们正在开发一个 QGIS 插件，参加"挑战杯"烽火通信主办的通信基建数智化设计比赛（子赛题1）。插件目标是让**没有任何 GIS 经验的设计人员**也能像用专业 CAD 工具一样完成基站网络设计。

当前插件已有基础骨架（6步向导、蜂窝拓扑、覆盖计算、管线、PDF导出），但效果像"学生作业"而非"专业工具"。

# 核心问题

1. **热力图不显示** — QGIS 3.44 兼容性问题，渲染方案需要彻底重构
2. **覆盖算法太粗糙** — 正方形网格而非圆形覆盖，忽略天线方向性
3. **管线纯几何连线** — 没有道路网络感知，共享检测几乎失效
4. **UI 像教程 demo** — 站点表格只有5列，无覆盖指标，无效率对比数据
5. **缺少专业感** — 没有频段对比、KPI 面板、3D 场景

# 请提供优化方案

## P0：热力图可视化重构

当前方案（逐点画圆）效果差。请推荐一个**专业通信设计软件级别**的覆盖可视化方案。

要求：
- 兼容 QGIS 3.44 + Python 3.12
- 支持多站点叠加（取最强信号）
- 颜色符合 3GPP 标准（RSRP 分级配色）
- 性能：100+ 站点 × 10000+ 点不卡顿

请给出：
1. 技术方案选型（GDAL 栅格 / QGIS 原生渲染器 / 其他），对比优缺点
2. 推荐的颜色方案（RGB + RSRP 阈值对照表）
3. 关键参数（半径、衰减因子、分辨率）

## P0：覆盖算法精度提升

1. 如何加入**天线扇区方向性增益**？（3扇区×120°，最简实现）
2. 最简单有效的**地形修正**方法？（DEM / 建筑遮挡）
3. 是否需要升级模型？（Okumura-Hata → COST 231 Hata → ITU-R P.1411），对比分析

## P1：专业级 UI 增强

1. 站点表格应展示哪些字段？（参考华为 UMG / 中兴网优工具的标准）
2. 如何实现**频段对比**功能？（700MHz vs 3.5GHz 叠加显示）
3. 导出图纸如何增加**设计说明页**？（项目信息 + 参数表 + 覆盖统计）

## P1：效率对比数据生成

比赛要求证明"效率提升≥30%"。请设计：
1. 自动化对比测试脚本（手动CAD vs 插件自动设计）
2. 真实场景数据（10km² 城区）的对比报告模板
3. 量化指标计算方法

## P2：演示增强

1. 3分钟演示视频脚本（分步骤、突出亮点）
2. 预置示例数据（一个完整的设计案例供评委直接体验）
3. 插件图标和 metadata 优化
