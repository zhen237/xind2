你是资深通信工程设计专家 + QGIS 插件架构师，精通 5G 网络规划、GIS 开发和专业设计软件 UX 设计。

# 背景

我们正在开发一个 QGIS 插件，参加"挑战杯"烽火通信主办的通信基建数智化设计比赛（子赛题1）。插件的目标是让**没有任何 GIS 经验的人**也能像用专业 CAD 工具一样完成基站网络设计。

当前插件已经具备基础骨架：6步向导式 UI、蜂窝拓扑生成、Okumura-Hata 覆盖计算、管线路由、PDF 导出。但效果不理想——热力图不显示、管线报错、整体观感像"学生作业"而非"专业工具"。

# 核心目标

帮我设计一套**完整的优化方案**，让插件从"能用"变成"专业"。优化方向必须紧扣比赛评分标准：

## 比赛评分关键维度（100分）

- **系统成熟度 (20分)**：核心功能完整可运行，演示效果好
- **方案完整性 (20分)**：参数化输入 → 自动化拓扑 → 场景构建 → 标准图纸 全链路
- **创新水平 (15分)**：AI 辅助布局、关键技术有突破
- **问题解决实效 (15分)**：设计效率提升 ≥30% 或 减少手动操作 ≥50%（需提供量化数据）
- **推广价值 (15分)**：可复制、可扩展、支持设计-施工-运维链条

# 具体问题清单

## 视觉/UX 问题
1. 热力图生成后不显示在地图上（QGIS 3.44 兼容性问题）
2. 管线生成时报错但成功（QgsMarkerLineSymbolLayer API 变更）
3. 站点表格只显示5列基础信息，没有天线/覆盖指标
4. 整体配色和排版偏"教程demo"，不像专业设计软件

## 功能/算法问题
1. 覆盖计算是**正方形网格**而非**圆形覆盖**，多站点叠加取最强信号但**不考虑方向性**（天线扇区角被忽略）
2. 管线路由是**纯几何连线**（直线/曼哈顿），没有道路网络感知
3. 共享管线检测在曼哈顿路由下几乎找不到共享路段
4. 避让检测只有**点是否在多边形内**，没有距离报告
5. 没有**频段对比**、**方案对比**、**KPI 仪表盘**

## 展示效果问题
1. 生成蜂窝拓扑后站点数上限硬编码200，超出静默截断
2. 没有**效率对比数据**（手动CAD vs 插件自动设计的时间/步骤对比）
3. 没有**3D 场景**（Cesium 风格的基站+天线+覆盖球）
4. 导出图纸只有标题+图例+比例尺，没有**覆盖统计面板**

# 请提供以下优化方案

## 第一部分：热力图可视化重构（最高优先级）

当前方案：逐点画圆 → 效果差。请推荐一个**真正像专业通信设计软件**的覆盖可视化方案。

要求：
- 兼容 QGIS 3.44（Python 3.12）
- 支持多站点叠加渲染
- 颜色方案符合通信行业标准（RSRP 分级配色）
- 性能好（100+ 站点 × 10000+ 覆盖点不卡顿）
- 有直观的图例和覆盖统计面板

请给出：
1. 推荐的技术方案（GDAL 栅格 / QGIS 原生渲染器 / 其他）
2. 具体的颜色方案（RGB 值 + RSRP 阈值）
3. 关键参数建议（半径、衰减因子、分辨率）

## 第二部分：覆盖算法精度提升

当前 Okumura-Hata 模型忽略了**天线方向性**和**地形**。请建议：
1. 如何在保持性能的前提下加入**扇区方向性增益**（3扇区 × 120°）
2. 最简单的地形修正方法（DEM 高程 / 建筑遮挡）
3. 是否需要引入更先进的模型（如 COST 231 Hata、ITU-R P.1411）？对比分析

## 第三部分：专业级 UI 重构

请给出具体建议：
1. 站点表格应该展示哪些字段？（参考华为 UMG / 中兴网优工具）
2. 如何加入"一键对比"功能（700MHz vs 3.5GHz 覆盖对比）
3. 管线路由增加"避让检测"的 UI 交互
4. 导出图纸增加"设计说明页"（含项目信息、参数表、覆盖统计）

## 第四部分：效率对比数据生成

比赛要求证明"效率提升 ≥30%"。请设计：
1. 一个自动化测试脚本，对比手动 CAD 设计 vs 插件自动设计的**步骤数/时间**
2. 用真实场景数据（如 10km² 城区）生成对比报告
3. 报告模板（含表格、截图位置、数据）

## 第五部分：演示增强

1. 如何制作一段 3 分钟的演示视频脚本？（分步骤、突出亮点）
2. 插件图标和 metadata 应该如何优化？
3. 是否需要加入"示例数据"（预置一个完整的设计案例供评委直接体验）？

# 约束条件

- **不引入重型依赖**：只能用 QGIS 内置的 Python 包（numpy、osgeo、shapely 可用，但不能要求评委安装 TensorFlow/PyTorch）
- **保持 6 步向导结构**：不要推翻现有 UI，而是在现有基础上增强
- **代码量可控**：每个优化建议不超过 200 行代码改动
- **中文界面**：所有标签、提示、报告都用中文
- **QGIS 3.44 LTR 兼容**：API 变更已知的坑不要踩
