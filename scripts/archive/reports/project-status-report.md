## 八、快速启动

### 8.1 启动后端

```bash
cd packages/m03-bim-gis/backend
mvnw spring-boot:run
```

### 8.2 启动前端

```bash
cd packages/m03-bim-gis/frontend
npm install
npm run dev
```

### 8.3 启动Python服务

```bash
cd packages/m03-topology-engine
pip install -r requirements.txt
python main.py
```

### 8.4 启动QGIS插件

```bash
# 在QGIS中
# 插件 -> 管理和安装插件 -> 从文件安装
# 选择 qgis-plugin/ 目录
```
