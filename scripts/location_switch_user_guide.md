# 位置切换功能使用指南

## 快速开始

### 1. 打开应用
访问: http://localhost:5174/modules/m03/

### 2. 查看当前位置
页面左下角显示当前选中的位置，例如：
```
[📍 运城学院 ▼]
```

### 3. 切换到武汉

**步骤**:
```
1. 点击位置选择器 "📍 运城学院"
   ↓
2. 在下拉菜单中选择 "📍 武汉"
   ↓
3. 确认切换（如果有关联数据）
   ↓
4. 地图自动飞到武汉位置
   ↓
5. 显示提示: "已切换到 武汉 (湖北省武汉市)"
```

**视觉效果**:
- 位置选择器变为: `[📍 武汉 ▼]`
- Cesium地图2秒动画飞到武汉
- 生成参数自动更新为武汉坐标

### 4. 生成武汉基站

```
1. 确认参数（应显示武汉坐标）
   - 经度: 114.39
   - 纬度: 30.506
   ↓
2. 点击 "生成方案" 按钮
   ↓
3. 等待生成完成
   ↓
4. 显示结果:
   - 总站点: 19个
   - 有效站点: 19个
   - 平均RSRP: -81.9 dBm
   ↓
5. 点击 "显示站点" 查看武汉基站布局
```

## 位置选项说明

- **坐标**: 110.932025, 35.123754
- **城市**: 山西省运城市
- **特点**: 页面加载时的默认位置

### 武汉

- **城市**: 湖北省武汉市
- **特点**: 光谷区域，高校密集

### 北京
- **坐标**: 116.4074, 39.9042
- **城市**: 北京市
- **特点**: 首都，一线城市

## 交互说明

### 悬停效果
鼠标悬停在位置选择器上时：
- 背景颜色加深
- 轻微放大（scale 1.05）
- 平滑过渡动画

### 切换确认
如果当前已有站点数据：
```
┌─────────────────────────────────┐
│ ⚠️ 切换位置                      │
│                                 │
│ 切换到武汉将清空当前站点数据，   │
│ 是否继续？                       │
│                                 │
│    [取消]    [确定]             │
└─────────────────────────────────┘
```

- 点击"确定": 清空站点，切换到新位置
- 点击"取消": 保持当前位置和数据

### 成功提示
切换成功后显示绿色提示：
```
✓ 已切换到 武汉 (湖北省武汉市)
```

## 常见问题

### Q1: 点击位置选择器没反应？
**A**: 确保页面已完全加载，检查浏览器控制台是否有错误信息。

### Q2: 切换到武汉后站点还在显示运城学院？
**A**: 切换位置后需要重新点击"生成方案"才能生成新位置的站点。

### Q3: 如何记住我选择的位置？
**A**: 当前版本刷新页面后会重置为默认位置。后续版本将支持位置持久化。

### Q4: 可以添加其他城市吗？
**A**: 可以！联系开发人员在LOCATION_CONFIG中添加新位置配置。

### Q5: 地图飞到新位置时很慢？
**A**: 这是正常的Cesium相机动画，持续2秒。网络状况可能影响加载速度。
